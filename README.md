# dsh-nexus · 奈克赛斯桌宠

一只住在 DeepSeek Harness 桌面上的 Q 版奥特战士桌宠。

本插件**不是**另起一套桌宠引擎：它把「奈克赛斯」做成 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的一个**种类包（pet pack）**，复用 dsh-pet 的全部能力（透明窗 / 拖拽抛掷 / 右键菜单 / 碎碎念 / 对话 / 余额 / 睡觉 / 会话事件联动）。

> 前置条件：已安装并启用 `dsh-pet`。本插件不修改 dsh-pet 包体，也不修改用户主配置 `main-config.jsonc`。

## 安装

**方式一：从插件市场索引安装（推荐）**

1. **插件** 页 → 展开 **实验性插件** → 打开 **自定义插件市场**
2. 出现 **发现** 标签 → **添加索引源**，粘贴：

   ```
   https://cdn.jsdelivr.net/gh/Ronion123/dsh-nexus@release-1.0.0/site/index.json
   ```

3. 找到「奈克赛斯桌宠」→ **安装** → 确认来源 `@ronion123/dsh-nexus@1.0.0`

**方式二：直接安装 npm 包**

```bash
dsh plugin --profile <你的 profile> add @ronion123/dsh-nexus
```

**方式三：从本地目录安装**（开发调试）

用 Plugin Manager 的 **Add plugin** 选择本仓库目录。

安装后：网页刷新即可；桌面端右键桌宠 →「重载配置」。

## 素材来源

全部素材均为你提供的透明背景图，**没有任何抠图步骤**——原图本身就是 RGBA 透明：

| 源文件 | 内容 | 用途 |
|---|---|---|
| `透明背景Q版英雄循环动画.gif` | 12 帧真实循环动画（160ms/帧） | 待机动画，直接使用原始逐帧画面 |
| `超人风格角色九格动作动画组.gif` | 9 个彼此独立的动作姿势（相邻帧差异 81–97%） | 九式连招动作池 |
| `站立/战斗/必杀光线/飞行/形态切换_herness.png` | 五张高分辨率透明立绘（268–664px 宽） | 五种形态 + 表情包 + 头像 |
| `五姿态赛博英雄贴纸合集.webp` | 1536×1024 总览图 | 角色参考图 |

处理流水线（`tools/build_assets.py`，不随运行时加载）：

1. **不做抠图**：直接读取原始 alpha 通道。
2. **分组统一缩放**：每组（循环 GIF / 九格 GIF / 五张 PNG）用该组内容高度的中位数算**一个**缩放系数，保留画师在姿势之间的相对比例。
3. **重心规则**：竖版姿势水平居中、脚底落在地面线 `y=336`；宽版姿势（宽高比 > 1.25，如飞行、横向放光）居中。循环 GIF 使用**固定并集包围盒**变换，避免逐帧重锚造成抖动。
4. **微幅呼吸**：静态立绘只叠加 2px 上浮呼吸（不改动画面内容），25/2 fps 编码。
5. **编码**：ffmpeg `libvpx-vp9` + `yuva420p`，640×360，CRF 28。已用 libvpx 解码器回读验证 alpha 真实存在（透明像素约 84–88%）。

共 **35 段**动画，1.11 MB。

## 姿势 → 玩法映射

| dsh-pet 动画池 | 映射 |
|---|---|
| `idle` | 待机-呼吸循环（**原始 12 帧循环动画**） |
| `turn` | 转向-回身 |
| `drag` | 拖拽-浮空（飞行姿势） |
| `clicks` | 点击-形态闪现 / 点击-光束 / 点击-迎击 |
| `moves` | 移动-飞行巡航 |
| `categories` | **九式连招**（起手式、连击式、展开式、横击式、蓄势式、爆发式、回旋式、疾飞式、展翼式，权重 58）<br>**形态**（站立、战斗、必杀光线、飞行、形态切换，权重 24）<br>**光之动作**（权重 8） |
| `events.balance` | 余额-充足 / 正常 / 告急 / 耗尽（6 档） |
| `events.whisper` | 碎碎念 |
| `events.workStatus` | 思考 / 忙碌 / 清点归档 / 踱步张望 / 雀跃庆祝 / 垂头叹气（6 档，对应 DSH 会话事件） |
| `sleep` | 入睡 → 睡觉循环 → 醒来 |
| `animationWeights` | idle 10 / turn 0 / move 0 + 分类 90 = 100 |

右键 →「动作」→「九式连招」可逐个点播九个动作。

## 台词

人设与全部台词取自 `台词.md` 的经典语录，写入 `whisperPrompt`（碎碎念由模型据此生成，每条 ≤20 字）：

> 我所为之战斗的，是宿命啊。/ 与我战斗的东西，那就是——宿命！/ 这个力量绝不是一种惩罚。/ 这份力量，是为了绝不放弃希望的人们而存在的！/ 过去已经不能改变，未来或许还可以改变。/ 光是一种纽带，当传到下一个继承者时，它会再次发出光芒的。/ 光……是纽带。被某人继承，再次闪耀……/ 这一次，我一定要守护给他们看……用这道光。/ 守护你重要的人吧，用那份力量。/ 我不能倒下，我的身后是万家灯火。

工作状态、睡觉、拒绝打扰等台词也按同一语气重写（「光需要收敛」「完成了。光没有熄灭」等）。

## 安装与生效

1. 用 Plugin Manager 的 **Add plugin** 安装本目录，或 `plugin_manager install_bundle`。
2. Host 启动时 `index.js` 幂等复制（内容哈希比对，只写变化的文件，不覆盖手改配置；标记文件可跨版本清理已下线的动画）。
3. **网页端**：刷新页面即可在桌宠设置页看到新「种类 nexus」。
4. **桌面端**：右键桌宠 →「重载配置」，或在设置页保存一次。

彻底移除：删除 `$DSH_HOME/dsh-pet/pet/` 下 `nexus-*` 文件与两个 `nexus-*` 目录。

## 已知限制

- 依赖 dsh-pet 0.4.7 的种类包约定；dsh-pet 大版本若调整 `animations` 形状或素材目录规则需同步更新。
- 九格 GIF 的 9 帧是**彼此独立的动作姿势**（相邻帧差异 81–97%），不是同一动作的分解，因此按「九个动作」而非「一段连招」使用；素材本身如此，未做补间。
- 静态立绘的动画只有 2px 呼吸，没有骨骼或变形动画。
- 素材来自你提供的角色图，仅作个人桌宠使用，不得商用或再分发。

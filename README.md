# dsh-nexus · 奈克赛斯桌宠

一只住在 DeepSeek Harness 桌面上的 Q 版奥特战士桌宠。

本插件**不是**另起一套桌宠引擎：它把「奈克赛斯」做成 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的一个**种类包（pet pack）**，复用 dsh-pet 的全部能力（透明窗 / 拖拽抛掷 / 右键菜单 / 碎碎念 / 对话 / 余额 / 睡觉 / 会话事件联动）。

> 前置条件：已安装并启用 `dsh-pet`。本插件不修改 dsh-pet 包体，也不修改用户主配置 `main-config.jsonc`。

## 安装

**方式一：从插件市场索引安装（推荐）**

1. **插件** 页 → 展开 **实验性插件** → 打开 **自定义插件市场**
2. 出现 **发现** 标签 → **添加索引源**，粘贴：

   ```
   https://raw.githubusercontent.com/Ronion123/dsh-nexus/v1.4.2/site/index.json
   ```

3. 找到「奈克赛斯桌宠」→ **安装** → 确认来源 `@roninxr/dsh-nexus@1.0.0`

**方式二：直接安装 npm 包**

```bash
dsh plugin --profile <你的 profile> add @roninxr/dsh-nexus
```

**方式三：从本地目录安装**（开发调试）

用 Plugin Manager 的 **Add plugin** 选择本仓库目录。

安装后：网页刷新即可；桌面端右键桌宠 →「重载配置」。

## 素材来源

全部素材均为你提供的透明背景图，**没有任何抠图步骤**——原图本身就是 RGBA 透明：

| 源文件 | 内容 | 用途 |
|---|---|---|
| `透明背景Q版英雄循环动画.gif` | 12 帧真实循环动画（160ms/帧） | 待机动画，直接使用原始逐帧画面 |
| `超人风格角色九格动作动画组.gif` | 9 个彼此独立的动作姿势（相邻帧差异 81–97%） | 九式连招动作池 |
| `站立/战斗/必杀光线/飞行/形态切换_herness.png` | 五张高分辨率透明立绘（268–664px 宽） | 五种形态 + 表情包 + 头像 |
| `五姿态赛博英雄贴纸合集.webp` | 1536×1024 总览图 | 角色参考图 |

处理流水线（`tools/build_assets.py`，不随运行时加载）：

1. **不做抠图**：直接读取原始 alpha 通道。
2. **分组统一缩放**：每组（循环 GIF / 九格 GIF / 五张 PNG）用该组内容高度的中位数算**一个**缩放系数，保留画师在姿势之间的相对比例。
3. **重心规则**：竖版姿势水平居中、脚底落在地面线 `y=336`；宽版姿势（宽高比 > 1.25，如飞行、横向放光）居中。循环 GIF 使用**固定并集包围盒**变换，避免逐帧重锚造成抖动。
4. **微幅呼吸**：静态立绘只叠加 2px 上浮呼吸（不改动画面内容），25/2 fps 编码。
5. **编码**：ffmpeg `libvpx-vp9` + `yuva420p`，640×360，CRF 28。已用 libvpx 解码器回读验证 alpha 真实存在（透明像素约 84–88%）。

共 **35 段**动画，1.11 MB。

## 双形态与单向转换（1.4.0 新增）

奈克赛斯有**红色青年形态**与**蓝色青年形态**两套素材，转换关系是**单向的**：

```
红色青年  ──形态转换──▶  蓝色青年        （蓝色无法变回红色）
```

### 怎么切

右键桌宠 → **更多** → **dsh-nexus** → **变成蓝色青年形态**。

### 为什么不会割裂

切换不是瞬间换图，而是按下述时序执行：

1. 红色形态播放 `形态切换` 动画（就是它本来就有的变身姿势）
2. 用 `/playback?wait=ended` **等这段动画真正播完**（实测等待 1.63 秒）
3. 动画结束后才隐藏红色、显示蓝色

所以看到的是「变身动画放完，蓝色站在原地」，而不是两只宠物同屏或突然替换。

> dsh-pet 的 `timeout` 上限是 10000ms，且必须与 `wait` 成对使用。传超限值会被拒绝并**立即返回**——那会被误判成「动画已结束」而在动画中途切换。实现里取上限值，并把任何非 `ended` 的回应都当作失败，绝不当成成功。

### 蓝色形态的素材

| 项 | 内容 |
|---|---|
| 姿势 | 站立 / 战斗 / 必杀光线 / **必杀弓箭** / 飞行 |
| 待机 | `蓝奈-1.gif` 的 9 帧循环（220ms/帧，保留原始节奏） |
| 动作 | `蓝奈动画九帧格-2.gif` 的 9 个独立动作 |
| 动画总数 | 36 段（红色 36 + 蓝色 36 = 72） |

蓝色形态**没有**「形态切换」片段——这是刻意的，保证单向性在素材层面就成立。

### 技术说明：为什么是两个宠物

dsh-pet 的素材根由配置文件前缀决定（`pet/<名>-config.json`），**运行时无法改**，所以同一只宠物不能换素材集。因此做成两个宠物实例：

| 宠物 | 配置文件 | 常态 |
|---|---|---|
| `nexus` | `nexus-config.json` | 显示 |
| `nexus-blue` | `nexus-blue-config.json` | 隐藏（`display: none`） |

切换时交换两者的 `display`，视觉上仍是同一位置的一只宠物。

## 音效与方向（1.1.0 新增）

### 点击音效换成角色战吼

点击桌宠播放的是**战吼**，不再是 dsh-pet 内置的鸭子叫声。

实现上有一个绕不开的限制：dsh-pet 把音效地址写死成客户端常量，它的 `/sound` 路由只读包内目录（源码注释明确写「不做用户目录覆盖」），而 DSH 的 webServer **不允许重复注册同一路径**（会直接抛错），所以插件无法拦截那条路由。

因此 Host 半侧在每次启动时**替换 dsh-pet 包内的 `assets/sound/click-duck.wav`**：
- 首次运行会把原文件备份成 `click-duck.wav.dsh-nexus-original`
- 按内容哈希比对，已是我们这份就不重复写
- **重装 / 升级 dsh-pet 后自动重新应用**，无需手动处理

想恢复原音效：把备份文件改名回 `click-duck.wav` 即可。

### 方向感知的飞行姿势

拖动、抛掷、顶部反弹**统一使用飞行姿势**，并且**朝向跟随鼠标移动方向**：

- 向左拖 → 播 `拖拽-飞行向左`，角色朝左飞
- 向右拖 → 播 `拖拽-飞行向右`，角色朝右飞

`client.js` 监听宠物元素上的指针移动，按水平位移方向调用 `/anim` 的 `facing` 参数（这是 dsh-pet 官方开放的控制通道）。位移小于 6px 的抖动会被忽略，避免手抖导致贴图闪烁。

两个方向的片段都是 640×360 VP9-alpha：左向为原始飞行图的镜像，右向反之。

## 图标与界面（1.2.0 新增）

### 全面替换为奈克赛斯图标

dsh-pet 有三处图标由它自己的包内文件提供，种类包无法覆盖（路由只读包内目录）。本插件在启动时替换它们：

| 位置 | 文件 | 效果 |
|---|---|---|
| 设置页头像 / 系统托盘角标 / 窗口与任务栏图标 | `assets/logo.png` | 全部变成奈克赛斯 |
| 系统通知弹窗图标（完成 / 出错 / 截断 / 等待批准 / 等待回答 / 测试） | `assets/pic/notify-*.png` | 六种通知各配对应姿势 |

图标都以深蓝圆角底衬 + 角色姿势合成，保证在 16–32px 的托盘尺寸下仍能辨认（纯白背景的立绘在通知区会糊成一片）。

原文件备份为 `*.dsh-nexus-original`，**重装或升级 dsh-pet 后会自动重新应用**。

### 只显示奈克赛斯

内置的「蓝毛小女仆」已设为 `display: none`，名字改为「（已停用）蓝毛小女仆」，不再出现在桌面与网页。

> 为什么要保留条目而不删除：dsh-pet 要求 `main` 条目存在，删掉它会让配置合并回落到内置默认值，女仆会重新出现。所以改为隐藏。

## 安装与生效

1. 用 Plugin Manager 的 **Add plugin** 安装本目录，或 `plugin_manager install_bundle`。
2. Host 启动时 `index.js` 幂等复制（内容哈希比对，只写变化的文件，不覆盖手改配置；标记文件可跨版本清理已下线的动画）。
3. **网页端**：刷新页面即可在桌宠设置页看到新「种类 nexus」。
4. **桌面端**：右键桌宠 →「重载配置」，或在设置页保存一次。

彻底移除：删除 `$DSH_HOME/dsh-pet/pet/` 下 `nexus-*` 文件与两个 `nexus-*` 目录。

## 已知限制

- 依赖 dsh-pet 0.4.7 的种类包约定；dsh-pet 大版本若调整 `animations` 形状或素材目录规则需同步更新。
- 九格 GIF 的 9 帧是**彼此独立的动作姿势**（相邻帧差异 81–97%），不是同一动作的分解，因此按「九个动作」而非「一段连招」使用；素材本身如此，未做补间。
- 静态立绘的动画只有 2px 呼吸，没有骨骼或变形动画。
- 素材来自你提供的角色图，仅作个人桌宠使用，不得商用或再分发。
